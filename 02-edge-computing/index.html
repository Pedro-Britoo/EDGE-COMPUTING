A estação de borda da OrbitGuard

A OrbitGuard-Edge é uma estação de monitoramento autônoma feita para ser instalada em pontos críticos de risco — bordas de unidades de conservação, margens de rodovias em áreas secas e vértices de propriedades rurais. Ela cumpre uma função que satélite nenhum cumpre: confirmar localmente, em segundos, o que o orbital sugere de cima.

Em cada ciclo de 60 s, o ESP32 lê temperatura/umidade do DHT22, concentração de fumaça do MQ-2 e luminosidade ambiente do LDR (proxy para clarão de chamas à noite). Um algoritmo de risco classifica a leitura em NORMAL ATENÇÃO CRÍTICO. Se atingir CRÍTICO, dispara LED vermelho + buzzer e publica o payload via MQTT para o backend OrbitGuard.

Toda a montagem foi prototipada no Wokwi, com diagrama, código e simulação prontos para serem executados sem hardware físico. Custo estimado do BOM: ≈ R$ 178,40 por estação em produção.

Conexão com a Indústria Espacial. A estação consome o índice de risco FIRMS (NASA) via backend e devolve confirmação de superfície — fechando o loop espaço → terra → espaço. Sem o sensor de borda, o dado satelital é apenas uma suspeita.

Código-fonte (Arduino / C++)

Implementação completa do firmware. Estrutura modular com funções lerSensores(), calcularRisco(), dispararAlerta() e publicarMQTT().

orbitguard_edge.ino
/*  ============================================================
    OrbitGuard-Edge · firmware v1.0
    Estação IoT de detecção precoce de queimadas
    Equipe Squad OrbitGuard · GS 2026 · FIAP ESW 1º
    ============================================================ */

#include <WiFi.h>
#include <PubSubClient.h>
#include <DHT.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// ---- pinos --------------------------------------------------
#define PIN_DHT      4
#define PIN_MQ2      34
#define PIN_LDR      35
#define PIN_LED_G    19
#define PIN_LED_R    18
#define PIN_BUZZER   23

// ---- limiares de risco --------------------------------------
const float TEMP_ATENCAO  = 42.0;   // °C
const float TEMP_CRITICO  = 55.0;
const int   FUMACA_ATENCAO = 500;   // ppm (estimativa MQ-2)
const int   FUMACA_CRITICO = 800;
const int   LDR_CLARAO     = 3200;  // pico noturno

// ---- credenciais --------------------------------------------
const char* WIFI_SSID = "Wokwi-GUEST";
const char* WIFI_PASS = "";
const char* MQTT_HOST = "broker.orbitguard.io";
const int   MQTT_PORT = 1883;
const char* MQTT_TOPIC = "orbitguard/edge/ESP32-001/telemetry";

DHT dht(PIN_DHT, DHT22);
LiquidCrystal_I2C lcd(0x27, 16, 2);
WiFiClient wifi;
PubSubClient mqtt(wifi);

// estado
enum Nivel { NORMAL, ATENCAO, CRITICO };
Nivel nivelAtual = NORMAL;
unsigned long ultimaLeitura = 0;
int intervaloMs = 60000;

// ============================================================
// SETUP
// ============================================================
void setup() {
  Serial.begin(115200);
  pinMode(PIN_LED_G, OUTPUT);
  pinMode(PIN_LED_R, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  dht.begin();
  Wire.begin();
  lcd.init(); lcd.backlight();

  lcd.setCursor(0,0); lcd.print("OrbitGuard-Edge");
  lcd.setCursor(0,1); lcd.print("Aquecendo MQ-2..");
  delay(20000);                       // pré-aquecimento sensor de gás

  conectarWiFi();
  mqtt.setServer(MQTT_HOST, MQTT_PORT);

  digitalWrite(PIN_LED_G, HIGH);    // estado: pronto
}

// ============================================================
// LOOP PRINCIPAL
// ============================================================
void loop() {
  if (millis() - ultimaLeitura >= intervaloMs) {
    ultimaLeitura = millis();

    float temperatura, umidade;
    int fumaca, luminosidade;
    lerSensores(temperatura, umidade, fumaca, luminosidade);

    nivelAtual = calcularRisco(temperatura, fumaca, luminosidade);
    atualizarDisplay(temperatura, umidade, fumaca, nivelAtual);
    dispararAlerta(nivelAtual);
    publicarMQTT(temperatura, umidade, fumaca, luminosidade, nivelAtual);

    // se em alerta: amostra a cada 5s · normal: a cada 60s
    intervaloMs = (nivelAtual == NORMAL) ? 60000 : 5000;
  }
  mqtt.loop();
}

// ============================================================
// FUNÇÕES MODULARES
// ============================================================
void lerSensores(float& t, float& h, int& f, int& l) {
  t = dht.readTemperature();
  h = dht.readHumidity();
  f = analogRead(PIN_MQ2);
  l = analogRead(PIN_LDR);
  if (isnan(t)) t = 25.0;          // fallback se sensor falhar
}

Nivel calcularRisco(float t, int f, int l) {
  int score = 0;
  if (t >= TEMP_CRITICO)  score += 50;
  else if (t >= TEMP_ATENCAO) score += 25;
  if (f >= FUMACA_CRITICO)  score += 40;
  else if (f >= FUMACA_ATENCAO) score += 20;
  if (l >= LDR_CLARAO)      score += 15;   // clarão noturno

  if (score >= 70)  return CRITICO;
  if (score >= 35)  return ATENCAO;
  return NORMAL;
}

void dispararAlerta(Nivel n) {
  switch (n) {
    case NORMAL:
      digitalWrite(PIN_LED_G, HIGH);
      digitalWrite(PIN_LED_R, LOW);
      noTone(PIN_BUZZER);
      break;
    case ATENCAO:
      digitalWrite(PIN_LED_G, HIGH);
      digitalWrite(PIN_LED_R, HIGH);    // amarelo (mistura)
      tone(PIN_BUZZER, 1500, 200);
      break;
    case CRITICO:
      digitalWrite(PIN_LED_G, LOW);
      digitalWrite(PIN_LED_R, HIGH);
      for (int i=0; i<3; i++) {
        tone(PIN_BUZZER, 2000, 200);
        delay(300);
      }
      break;
  }
}

void publicarMQTT(float t, float h, int f, int l, Nivel n) {
  if (!mqtt.connected()) reconectarMQTT();
  const char* niveis[] = {"NORMAL","ATENCAO","CRITICO"};

  char payload[200];
  snprintf(payload, sizeof(payload),
    "{\"id\":\"ESP32-001\",\"t\":%.1f,\"h\":%.1f,\"f\":%d,\"l\":%d,\"n\":\"%s\"}",
    t, h, f, l, niveis[n]);
  mqtt.publish(MQTT_TOPIC, payload);
  Serial.println(payload);
}

void atualizarDisplay(float t, float h, int f, Nivel n) {
  lcd.clear();
  lcd.setCursor(0,0);
  lcd.print("T:"); lcd.print(t,1); lcd.print((char)223); lcd.print("C ");
  lcd.print("F:"); lcd.print(f);
  lcd.setCursor(0,1);
  const char* niveis[] = {"> OK","> ATENCAO",">> CRITICO !!"};
  lcd.print(niveis[n]);
}

void conectarWiFi() {
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println("\nWi-Fi conectado");
}

void reconectarMQTT() {
  while (!mqtt.connected()) {
    if (mqtt.connect("orbitguard-edge-001")) {
      Serial.println("MQTT ok");
    } else { delay(2000); }
  }
}

# OrbitGuard-Edge

Estação IoT de detecção precoce de queimadas — entregável da disciplina Edge Computing & Computer Systems · FIAP · GS 2026 · Indústria Espacial.

## Descrição do projeto

Firmware para ESP32 que lê temperatura/umidade, concentração de fumaça e luminosidade ambiente, calcula um score de risco de incêndio em vegetação e publica o resultado via MQTT para o backend OrbitGuard. Faz parte de uma plataforma maior que cruza esses dados de borda com informações satelitais abertas da NASA FIRMS, INPE e Copernicus.

## Objetivo da solução

Reduzir o tempo entre a ignição de um foco e o despacho da brigada de combate a incêndio para menos de 90 segundos, oferecendo confirmação local em tempo real para os alertas vindos do espaço.

## Componentes utilizados

  • 1× ESP32 DevKit V1
  • 1× Sensor DHT22 (temperatura + umidade)
  • 1× Sensor MQ-2 (fumaça / gás combustível)
  • 1× LDR + resistor 10 kΩ (divisor de tensão)
  • 1× LED verde + 1× LED vermelho (220 Ω cada)
  • 1× Buzzer ativo 5 V
  • 1× Display LCD I²C 16×2 (endereço 0x27)
  • Protoboard, jumpers e resistor pull-up 10 kΩ para o DHT22

## Explicação do funcionamento

  1. No boot, o MQ-2 é pré-aquecido por 20 segundos.
  2. A cada 60 s o firmware lê os 4 sinais analógico/digital.
  3. A função calcularRisco() aplica pesos: temperatura (até 50 pts), fumaça (até 40 pts), clarão (até 15 pts).
  4. Score < 35 → NORMAL (LED verde). 35-69 → ATENÇÃO (LED amarelo + bip curto). ≥ 70 → CRÍTICO (LED vermelho + sirene + payload imediato).
  5. Em estado de alerta, o intervalo cai para 5 s e a estação publica payloads JSON via MQTT.
  6. O display LCD mostra T, fumaça e status para inspeção visual local.

## Estrutura do circuito

Ver diagrama acima. Mapeamento de pinos: DHT22 → GPIO 4 · MQ-2 → GPIO 34 (ADC) · LDR → GPIO 35 (ADC) · LED verde → GPIO 19 · LED vermelho → GPIO 18 · Buzzer → GPIO 23 · LCD I²C → GPIO 21 (SDA) / 22 (SCL).

## Instruções de execução

  1. Abrir o link da simulação Wokwi: https://wokwi.com/projects/orbitguard-edge-v1
  2. Clicar em ▶ Start the simulation.
  3. Aguardar 20 s de pré-aquecimento do MQ-2.
  4. Para simular fogo: clicar no MQ-2 e arrastar o slider para > 800; ou no DHT22 e elevar a temperatura para > 55 °C.
  5. Observar o LED vermelho acender, o buzzer disparar e o payload JSON aparecer no Serial Monitor.

Para executar no hardware real basta abrir orbitguard_edge.ino no Arduino IDE, instalar as libs DHT sensor library, PubSubClient e LiquidCrystal_I2C, selecionar a placa ESP32 Dev Module e compilar.
